# Template tool entry

`index.js` registers the **Template Studio v3** (`apps/web/modules/template-studio/`) as the
`template-builder` AI tool. See `docs/TEMPLATE_STUDIO_ARCHITECTURE.md` for the model and
`modules/template-studio/README.md` for the module layout.

`TemplateBuilderPage.js` is the legacy block editor, kept only for reference until M2.
